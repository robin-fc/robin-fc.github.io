# 量化系统性学习计划

个人量化学习的长期计划：**学 K 线指标理论，写 BTC 策略验证**。一个文件讲透 1~3 个知识点。

## 规则

- **学习 = 纯理论**：专攻 K 线 / 技术指标（均线、池子、缩量放量、斐波那契、江恩、波浪…），把每个术语吃透。
- **实践 = 写策略验证**：以 BTC 等虚拟货币为主标的，用可回测策略巩固理解（不追稳赚，追看懂）。
- **一个文件 = 1~3 个知识点 + 一个最小验证**；K 线类知识点配 SVG 插图。
